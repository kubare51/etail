PortMax — User Manual

Step-by-step guide for importing data from Excel files into your destination database

📋 Version 2.1 📅 April 2026 🏢 Logimax

Overview

PortMax is a web-based data migration tool that helps you import bulk data from Excel spreadsheets into your destination database. It validates every row before inserting, detects duplicates, resolves references (like city/state names to IDs), and gives you detailed reports after each import.

💡
The tool automatically backs up your database tables in both Excel and SQL format before importing, and again after importing (on the report page), so you can safely restore if needed.

Step 1: Login

1 Enter Your Credentials

Enter your username and password (same as your application login). The system connects to your company database automatically.

  • Your Client Name (company name) will be displayed after successful login
  • The session persists even if you refresh the page
⚠️
If you see "Invalid username or password", verify your credentials. The password is case-sensitive.

Use this template to prepare your data with the correct columns and formatting before uploading.

2c Upload the File (Auto-Upload)

Files are auto-uploaded on selection. You can upload in two ways:

  • Drag & Drop: Drag the file directly onto the upload area
  • Browse: Click on the upload area to open the file browser

The file is uploaded immediately after you select it — no separate upload button needed.

🔄 Reset

Click the "🔄 Reset" button (located next to the Download Template button) to clear the current entity selection, uploaded file, and all validation results. This lets you start over without refreshing the page.

Step 3: Validate Data

3 Click "Validate" to Start

The system checks every single row in your Excel file against the rules defined in the config template:

  • ✅ Required fields: Ensures mandatory columns are not empty
  • ✅ Data types: Validates numbers, text, and dates
  • ✅ Length limits: Checks maximum character length
  • ✅ Lookups: Resolves names like City, State, Village to database IDs
  • ✅ Duplicate check: Detects if records already exist in the database

A progress bar shows real-time validation progress. This runs in the background — please wait until it completes.

Validation Results

ResultWhat Happens
✅ No ErrorsBackup starts automatically, then Import button appears
⚠️ Has Errors (with valid rows)User is prompted to choose: Skip Errors & Import valid rows, or Fix Errors First
❌ All ErrorsError table is shown with row numbers and error details. Import is blocked — all rows must be fixed.

Skip or Fix Prompt

⚠️ When Errors Are Found With Valid Rows

If some rows have errors but others are valid, the system shows two buttons:

  • ✅ Skip Errors & Import N Valid Row(s) — Skips error rows and proceeds to backup + import with only the valid rows
  • 🔧 Fix Errors First — Stops the process and shows error details with a download button so you can fix the Excel and re-upload

This is useful when you have a large file with a few errors and want to import the valid data immediately, then fix and re-import the errors later.

Fixing Validation Errors

! Download & Fix Errors

If validation finds errors:

  1. Click "Download Errors" to get the Excel file with an added Error column
  2. Open the file and check the Error column for each row's specific issues
  3. Fix the issues in your original Excel file
  4. Re-upload the corrected file and validate again
📝
Error Column Prefixes: Each entry in the Error column is prefixed to indicate the type:
  • Skipped: — Row was skipped due to a duplicate record already existing in the database
  • Error: — Row has validation errors (required field missing, invalid type, lookup not found, etc.)
  • Child Error: — Error is in a child record (e.g., address fields)

Step 4: Auto Backup (Pre-Import)

4 Automatic Dual Backup (Before Import)

When validation succeeds with zero errors, the system automatically creates two backups of all related destination database tables before importing:

  • ⏳ You'll see "Backing up entity tables..." message
  • ✅ Once done, a green card shows each table name and row count
  • 📥 Excel Backup button — downloads an .xlsx file with each table as a separate sheet (human-readable)
  • 🗃️ SQL Backup button — downloads a .sql file with full CREATE TABLE + INSERT statements (restore-ready)
  • 📁 Backups are saved at: tmp/backups/
🛡️
Both download buttons appear in the green backup result card. The Excel backup lets you review data in spreadsheet format, while the SQL backup can be used by your DBA to fully restore tables if anything goes wrong during import.
🔄
Post-Import Backup: An additional backup is also taken automatically after import when the report page loads. This gives you two restore points — one before and one after import.

Step 5: Import Data

5 Click "⚡ Import N Row(s) Now"

After backup completes, a prominent full-width orange-red button appears showing the exact row count:

⚡ Import 12 Row(s) Now

Clicking this button opens a confirmation modal:

  • ⚠️ Shows the entity name and row count being imported
  • Warns that data will be inserted directly into the production database
  • Two buttons: "Cancel" to abort, or "Yes, Import Now" to proceed

After confirming, the import starts:

  • The Import progress card appears with a real-time progress bar
  • Parent records are inserted first (e.g., Customer), then child records (e.g., Address)
  • All inserts happen within a database transaction — if any critical error occurs, everything is rolled back
  • If a database error occurs (e.g., constraint violation), the error message is displayed to the user instead of failing silently
🚫
Do NOT close the browser or navigate away while import is in progress. Wait for the progress to reach 100%.

Step 6: View Import Report

6 Review the Report

After a successful import, click "View Report" to see the migration summary. The report page has:

  • 📊 Summary cards: Total Rows (Excel), Imported, Skipped, and Errors counts
  • 📥 Error/Skipped download: If any rows were skipped or had errors, a "📥 Download Error / Skipped Rows Report" button appears below the summary cards — click it to download the Excel file with the Error column
  • 💾 Auto backup: A post-import backup runs automatically when the report loads
  • 📋 Report tables: Aggregated data grouped by branch, source, etc. with totals
  • 📈 Numbers are displayed with comma formatting (e.g., 1,234)

Export Report as Excel

📥 Download Report XLSX

Click the "Export Excel" button on the report page to download a styled spreadsheet. The file is named with the entity name, e.g., Customer_report_2026-03-20_183546.xlsx:

  • 🔵 Title row: Dark blue background with entity name
  • 🟢 Header row: Green background with white bold text
  • ⬜ Data rows: Numbers right-aligned with comma formatting
  • ⬛ Total row: Bold with gray background

Export Database Table Data

📁 Export Raw Table Data

On the report page, you'll find the "Export Raw Table Data" section:

  1. Select a table from the dropdown (e.g., customer, address)
  2. Click "Export All Columns"
  3. Downloads a complete XLSX file with all data from that table

Combined Data Export

🔗 Export Combined Main + Child Tables

The "Export Combined Data" section lets you export data from related tables (e.g., Customer + Address) in a single file:

  1. You'll see columns grouped by table name (e.g., CUSTOMER, ADDRESS)
  2. Each column has a checkbox — uncheck columns you don't need
  3. Click "Export Combined"
  4. The system performs a LEFT JOIN and exports only selected columns
💡
Combined export is useful when you need customer data with their addresses in a single spreadsheet, with only the columns you care about.

FAQ & Troubleshooting

Q: My file uploads but validation fails immediately. Why?
A: Check that your Excel file has the correct sheet name. For example, the customer template requires a sheet named port_customer. Also verify you selected the right config template.
Q: Validation is slow for large files. Is that normal?
A: Yes, each row is validated individually with database lookups. For 10,000+ records, validation may take 1-3 minutes. The progress bar shows real-time progress. Do not close the browser.
Q: I see "Lookup not found" errors. What should I do?
A: This means the city/state/village name in your Excel doesn't match any record in the database lookup table. Check for typos or add the missing entries to the lookup table first. Some lookups have create_if_missing enabled (like Village) which auto-creates the entry.
Q: Can I import the same file twice?
A: If duplicate detection is enabled (e.g., check_if_exists on mobile number), duplicate rows will be skipped automatically. They'll appear in the "Skipped Rows" count.
Q: The import failed halfway. Is my data corrupted?
A: No. Imports run inside a database transaction. If the import fails, all changes are automatically rolled back. Additionally, both an .xlsx and .sql backup were created before the import started. You can download them from the backup result card, or contact your DBA to restore using the SQL file.
Q: Where are the backup files stored?
A: Backup files are saved in the tmp/backups/ directory on the server. Each backup creates two files — e.g., customer_backup_20260404_184628.xlsx and customer_backup_20260404_184628.sql. You can also download them directly from the green backup card in the UI.
Q: How do I start a new migration after viewing the report?
A: Click the "Start New Migration" button on the report page. This takes you back to the upload screen.
Q: The page refreshed and I lost my progress. What now?
A: The tool saves your session state. After refresh, you should return to the same step. If you were mid-validation or mid-import, you may need to restart that step.
Q: How do I download skipped/error row details from the report page?
A: If any rows were skipped or had errors, a "📥 Download Error / Skipped Rows Report" button appears below the summary cards. Click it to download the Excel file with the Error column showing why each row was skipped or errored. Each entry is prefixed with Skipped: or Error: for clarity.
Q: Can I import valid rows even if some rows have errors?
A: Yes! When validation finds errors but also valid rows, the system shows two options: "Skip Errors & Import" to proceed with only the valid rows, or "Fix Errors First" to stop and correct the data. The error rows will be excluded from the import, and you can download the error report from the report page after import.
Q: What backup formats are available?
A: Before import, PortMax creates two backup files: an Excel (.xlsx) backup (each table as a separate sheet for easy review) and a SQL (.sql) backup (full CREATE TABLE + INSERT statements for database restore). Both are downloadable from the green backup card. A second SQL backup is also created after import when the report page loads.
