1. Project Overview

1.1 Purpose

The PortMax is a web-based data migration platform that enables importing bulk data from Excel/ODS files into a MySQL database. It supports configurable entity mapping, field validation, lookup resolution, parent-child table relationships, and comprehensive reporting.

MY_Controller (Base)

MY_Controller extends CI_Controller

AuthController

AuthController extends MY_Controller

3.3 Validation Engine (Detail)

validateProcess($data)
│
├── Load entity config JSON
├── Map Excel header row → config column mappings
│
├── FOR EACH ROW:
│   ├── FOR EACH COLUMN in config.mappings:
│   │   │
│   │   ├── Direct Column?
│   │   │   └── validateField(value, rules)
│   │   │       ├── type: string  → max_length check
│   │   │       ├── type: numeric → is_numeric, min, length
│   │   │       ├── type: date    → format parse (Y-m-d)
│   │   │       └── required      → empty check
│   │   │
│   │   ├── Lookup Column?
│   │   │   └── lookupValue(table, matchCol, value, returnCol, createIfMissing)
│   │   │       ├── Check bulkCache[] first (O(1))
│   │   │       ├── Cache miss → DB query
│   │   │       ├── Not found + createIfMissing → INSERT + return new ID
│   │   │       └── Store result in bulkCache[]
│   │   │
│   │   └── check_if_exists?
│   │       └── checkDataExists(table, col, value) → duplicate detection
│   │
│   ├── Validate CHILDREN (same logic, nested mappings)
│   │
│   ├── Has errors?    → add to ErrorRows[]
│   ├── Is duplicate?  → add to SkipedRows[]
│   └── Valid?         → add to allrows[]
│
├── Write progress to status JSON file (for polling)
└── Return: { ErrorRows, SkipedRows, message (valid rows) }

3.4 Import Engine (Detail)

insertProcess($input, $taskId)
│
├── Start DB Transaction
│
├── FOR EACH ROW in allrows:
│   ├── INSERT into destination_table → get insert_id (primary key)
│   ├── FOR EACH CHILD:
│   │   ├── Set foreign_key = parent insert_id
│   │   └── INSERT into child destination_table
│   │
│   ├── Update status file progress (every N rows)
│   └── On error → rollback + mark failed
│
├── Commit transaction
├── Generate post-import report data
└── Write final status: completed / failed

3.5 Backup Engine (Detail)

backupEntityTables($client, $entity)
│
├── Read config JSON → collect all table + destination_table names 
│   (main + children, deduplicated)
│
├── 1. EXCEL BACKUP (.xlsx)
│   ├── Create WriterEntityFactory::createXLSXWriter()
│   └── FOR EACH TABLE:
│       ├── Create sheet (name = table, max 31 chars)
│       ├── Write blue bold header row
│       └── Write all data rows
│
├── 2. SQL BACKUP (.sql)
│   ├── Header comments (entity, client, date, tables)
│   ├── SET FOREIGN_KEY_CHECKS=0
│   └── FOR EACH TABLE:
│       ├── SHOW CREATE TABLE → get DDL
│       ├── SELECT * FROM table → get all data rows
│       │   └── Generate batch INSERT statements (500 rows per INSERT)
│       └── Track: table name + row count
│
├── Save Excel to: tmp/backups/{entity}_backup_{timestamp}.xlsx
├── Save SQL to:   tmp/backups/{entity}_backup_{timestamp}.sql
└── Return: { excelFile, sqlFile, downloadUrl, sqlDownloadUrl, tables[] }

3.6 Report Engine

generateReport($client, $configFile)
│
├── Read config.report[] array (list of report queries)
│
├── FOR EACH report entry:
│   ├── Build SELECT from config.select
│   ├── FROM destination_table
│   ├── LEFT JOIN (if config.left_join defined)
│   ├── WHERE conditions:
│   │   ├── Fixed filters (e.g., added_by = 6)
│   │   └── current_import filter (id > lastImportId)
│   ├── GROUP BY config.group_by
│   └── Execute query → collect result rows + totals
│
└── Return: { tables: [{ title, columns, rows, summary }] }

7. Database & Storage Design

7.1 Session Management

PHP sessions store db_config (host, user, password, database). MY_Controller::loadClientDB() restores the DB connection on each request. Login state is tracked via logged_in and username session keys.

7.2 File Storage Layout

uploads/
├── {ClientName}/
│   ├── uploaded_file.xlsx              # Original upload
│   ├── uploaded_file_processed.xlsx    # With error column added
│   ├── import_log_{fileId}.json        # Import activity log
│   │
│   ├── imported/
│   │   ├── uploaded_file.xlsx          # Archived after import
│   │   └── 2026-04-04.txt             # Activity log
│   │
│   └── summary/
│       ├── {Entity}_report_*.xlsx      # Summary reports
│       └── customer_data_*.xlsx        # Exported table data

tmp/
├── backups/
│   ├── customer_backup_20260404_184628.xlsx   # Excel backup (per-table sheets)
│   └── customer_backup_20260404_184628.sql    # SQL backup (CREATE + INSERT)
└── status_{taskId}.json                      # Async progress tracking

7.3 Async Status File Format

{
  "status": "processing | validated | has_errors | completed | failed",
  "progress": 0-100,
  "validRowCount": 10,           // (has_errors only) count of valid rows
  "errorRowCount": 5,            // (has_errors only) count of error rows
  "data": {
    "ErrorRows":   [{ row#, errors[] }],
    "SkipedRows":  [{ row#, reason }],
    "message":     [{ valid row data }],
    "ErrorSummary": "optional summary text"
  },
  "allrows": [/* all valid rows for import */],
  "message": "error description if failed"
}
