# Forge — Training Data Forge

Extract, curate, and export AI training data from conversation transcripts.

## Install

```bash
pip install -e .
```

## Usage

```bash
forge harvest           # Extract examples from all conversations
forge export            # Export in ShareGPT/Alpaca format
forge stats             # Dataset statistics
forge conversations     # List available conversations
forge inspect -i 0      # Inspect a specific example
```
