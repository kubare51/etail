Codebase Indexing & Analysis

Build a searchable dependency graph of your entire codebase. Parse PHP, JavaScript, and Python files to map every function call, class dependency, and data flow.

🗃
lca index
Parse a file or directory and build a function-call dependency map. Supports PHP, JS, and Python. This is the foundation — most other commands depend on the index.
lca index admin/application/controllers/ --name billing_index
CLI MCP: index_module Ready
🚀
lca index (fullstack)
Index the entire application stack in one call: controllers, models, JS, and SQL views. Produces a combined index with cross-resolution (AJAX → Controller → Model → DB Table).
lca index C:\xampp\htdocs\etail_v3 --fullstack
CLI MCP: index_fullstack Unlocks 5 commands
🔄
lca update
Incrementally re-index only files that changed since last index. Fast — takes seconds instead of minutes.
lca update --index billing_index.json
CLI Ready
🔎
lca search
Search for functions by name across the entire indexed codebase. Case-insensitive, pattern-based matching.
lca search "calculateDiscount" --index billing_index.json
CLI MCP: search_functions
🔗
lca crossref
Extract cross-language dependencies: maps JavaScript AJAX calls to PHP controller methods. Essential for tracing the full request lifecycle.
lca crossref --index fullstack_index.json --controller billing
CLI MCP: get_ajax_endpoints
🏗
lca modules
Analyze high-level architecture: module-to-module dependencies, which modules share tables, and which modules call each other.
lca modules --index fullstack_index.json
CLI Ready
🗂
lca sql-map
Map which PHP functions read from or write to which database tables. Critical for understanding data flow and planning schema changes.
lca sql-map admin/application/models/
CLI MCP: sql_map, get_table_usage

Risk & Impact Analysis

Score regression risk before deployment. Trace the full blast radius of any code change across functions, modules, AJAX routes, and database tables.

🔥
lca risk
Score regression risk for files using: git churn (commit frequency) × code complexity × author count. Identifies bug magnets — files most likely to cause production incidents.
lca risk . --branch --base PRODUCTION

admin_app_api.php             MEDIUM   35/100 (8 commits, CC=38)

healthcheck.php               LOW      10/100 (1 commit, CC=12)

Git Hooks — 3 Hooks

Local enforcement layer — validates commits, enriches messages, and blocks dangerous pushes before code ever leaves the developer's machine.

✅
commit-msg ENABLED
Auto-enriches commit messages via LCA. If the developer writes a bare "fixed stuff" message, LCA replaces it with fix(billing): correct discount calc. Already-structured messages pass through untouched.
# Configuration in .githooks/config: COMMIT_MSG=on # Enable/disable # Priority order: # 1. .changes/current.json (if changeset exists) # 2. Auto-detect from staged diff (module detection) # 3. Reject if still unstructured
Git Hook Active
⚠️
pre-commit DISABLED
When enabled, runs lint and format checks before allowing a commit. Can enforce PHP syntax checks, JS linting, and file size limits.
# Enable in .githooks/config: PRE_COMMIT=on
Git Hook Disabled
🚫
pre-push DISABLED
When enabled, blocks direct pushes to protected branches (PRODUCTION, QA, support). Forces developers to use Pull Requests.
# Enable in .githooks/config: PRE_PUSH=on
Git Hook Disabled
