🆕 New Client Setup

Complete setup for a brand new client from scratch

0 Overview

Setting up a new client involves:

  • Create GitHub repo in LOGIMAX-CLIENTS
  • Setup server (cPanel or AWS)
  • Configure shared directories
  • Deploy CI/CD scripts
  • Initial code deployment

1 Create GitHub Repository

# Using GitHub CLI gh repo create LOGIMAX-CLIENTS/client-domain.com --private # Clone and setup git clone git@github.com:LOGIMAX-CLIENTS/client-domain.com.git cd client-domain.com # Copy base code from retail_v5 cp -r /path/to/retail_v5/* . # Create branches git checkout -b staging git push -u origin staging git checkout -b production git push -u origin production

2 Setup Server Directory Structure

For Production (Symlink Mode)

/var/www/ (or /home/user/)
├── releases/         # Versioned releases
├── shared/           # Persistent data
│   ├── logs/
│   ├── uploads/
│   ├── img/
│   ├── bill_qrcode/
│   ├── admin/
│   │   ├── log/
│   │   ├── kyc/
│   │   └── vendor_ack/
│   ├── database.php
│   ├── global_configs.php
│   └── config.php
└── current/ → releases/latest/
# Create structure on server ssh user@server # Create directories mkdir -p ~/releases ~/shared/{logs,uploads,img,bill_qrcode,esti_qrcode} mkdir -p ~/shared/admin/{log,kyc,vendor_ack,tagging_log} # Create config files cp database.php ~/shared/ cp global_configs.php ~/shared/

3 Deploy CI/CD Scripts

# From your local machine # Copy deployment scripts scp scripts/unified-deploy.sh user@server:~/deploy.sh scp scripts/rollback.sh user@server:~/rollback.sh scp scripts/webhook-handler.php user@server:~/webhooks/deploy.php scp maintenance.html user@server:~/shared/maintenance.html # Make executable ssh user@server "chmod +x ~/deploy.sh ~/rollback.sh"

4 Configure Environment Variables

Generate Secrets

# Generate webhook secret WEBHOOK_SECRET=$(openssl rand -hex 32) echo "Webhook Secret: $WEBHOOK_SECRET"

Server Configuration

# Create ~/webhooks/.htaccess (cPanel) SetEnv WEBHOOK_SECRET "your-generated-secret" SetEnv REPO_PATH "/home/username/current" SetEnv DEPLOY_SCRIPT "/home/username/deploy.sh" SetEnv BASE_DIR "/home/username" SetEnv RELEASES_DIR "/home/username/releases" SetEnv SHARED_DIR "/home/username/shared" SetEnv CURRENT_LINK "/home/username/current"

5 Add GitHub Secrets

SecretValue
STAGING_WEBHOOK_URLhttps://client.com/webhooks/deploy.php
STAGING_WEBHOOK_SECRET(generated secret)
PRODUCTION_WEBHOOK_URLhttps://client.com/webhooks/deploy.php
PRODUCTION_WEBHOOK_SECRET(generated secret)
# Using GitHub CLI gh secret set STAGING_WEBHOOK_URL --repo LOGIMAX-CLIENTS/client-domain.com gh secret set STAGING_WEBHOOK_SECRET --repo LOGIMAX-CLIENTS/client-domain.com gh secret set PRODUCTION_WEBHOOK_URL --repo LOGIMAX-CLIENTS/client-domain.com gh secret set PRODUCTION_WEBHOOK_SECRET --repo LOGIMAX-CLIENTS/client-domain.com

6 Add Workflow File

# Create .github/workflows/deploy.yml mkdir -p .github/workflows cp templates/client/deploy.yml .github/workflows/deploy.yml git add .github/ git commit -m "Add CI/CD workflow" git push

7 Setup GitHub Environment Protection

For production approval:

  1. Go to repo → Settings → Environments
  2. Click "New environment" → Name: production
  3. Check "Required reviewers" → Add approvers
  4. Under "Deployment branches" → Select "production" only
  5. Save

8 Initial Deployment

# Push to staging first git checkout staging git push origin staging # Watch GitHub Actions for status gh run watch # Once staging works, deploy to production git checkout production git merge staging git push origin production # Approve in GitHub → Actions → Pending deployments
✅ Success! Your new client is now set up with full CI/CD!

📋 Final Checklist

  • GitHub repo created in LOGIMAX-CLIENTS
  • staging and production branches created
  • Server directories created (releases, shared)
  • Config files in shared/ directory
  • Deploy scripts copied to server
  • Webhook secret generated and configured
  • GitHub secrets added
  • Workflow file added
  • Production environment protection enabled
  • Staging deployment tested
  • Production deployment tested
