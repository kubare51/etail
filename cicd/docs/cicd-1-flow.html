⚖️ Staging vs Production

Feature🟢 Staging🔴 Production
Deployment ModeSimple (git pull)Symlink (zero-downtime)
Auto Deploy✓✗ Requires Approval
Maintenance Mode✗✓
Email Report✗✓
Instant Rollback✗✓

🟢 Staging Deployment Steps

📥 Fetch All

git fetch --all

📍 Checkout Branch

git checkout staging

💾 Stash Changes

git stash (if local changes exist)

🔄 Reset & Pull

git reset --hard && git pull --no-rebase

🔙 Restore Stash

git stash pop (if stashed)

🔴 Production Deployment Steps

✅ Approval

Reviewer approves in GitHub

🔧 Maintenance ON

touch .maintenance

📁 Create Release

/releases/20260108_192500/

📥 Clone Fresh

git clone --depth 1

🔗 Link Shared

Symlink uploads, logs, config

⚡ Atomic Swap

mv -Tf new current

🔧 Maintenance OFF

rm .maintenance

📧 Send Report

Email to team

📁 Production Directory Structure

/var/www/
