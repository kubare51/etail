Phase 1 — Local Setup LOCAL 5 min

1 Create client JSON

File: config/clients/{CLIENT_ID}.json

{
  "client_name": "{CLIENT_NAME}",
  "features": [], "flags": {},
  "deploy": {
    "ssl_verify": false,
    "staging": {
      "webhook_url": "https://{DOMAIN}/webhooks/deploy.php",
      "branch": "support"
    },
    "production": {
      "webhook_url": "https://{DOMAIN}/webhooks/deploy.php",
      "branch": "Production"
    }
  }
}

2 Create override dir

mkdir -p clients/{CLIENT_ID}/assets
touch clients/{CLIENT_ID}/assets/.gitkeep

3 Commit & push

git add -f config/clients/{CLIENT_ID}.json \
  clients/{CLIENT_ID}/
git commit -m "Add client: {CLIENT_ID}"
git push origin support
✅ GitHub Actions auto-detects new client. Zero workflow changes.

Phase 2 — SSH Deploy Key SERVER GITHUB 5 min

4 Generate key (skip if key already exists on server)

ssh -i {SSH_KEY_PATH} ubuntu@{SERVER_IP}
ssh-keygen -t ed25519 -C "{CLIENT_ID}-server" -f /home/ubuntu/.ssh/id_ed25519 -N ""
cat /home/ubuntu/.ssh/id_ed25519.pub    # Copy this

5 Add to GitHub → repo Settings → Deploy Keys → Add → paste public key → ✅ Write access

6 Verify: ssh -i /home/ubuntu/.ssh/id_ed25519 -T git@github.com

Phase 3 — Database Migration SERVER 15 min

7 Create databases

mysql -h {RDS_ENDPOINT} -u {DB_USER} -p

CREATE DATABASE {DB_NAME_PROD}
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_general_ci;
CREATE DATABASE {DB_NAME_STAGING}
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_general_ci;

8 Export → Strip → Import

# Export
mysqldump -h {SOURCE_RDS} -u {USER} -p \
  --set-gtid-purged=OFF --single-transaction \
  --routines --triggers {SOURCE_DB} \
  > /tmp/{CLIENT_ID}_dump.sql

# Strip DEFINER (RDS requirement)
sed -i 's/DEFINER=`[^`]*`@`[^`]*`//g' \
  /tmp/{CLIENT_ID}_dump.sql

# Import prod + staging
mysql -h {RDS_ENDPOINT} -u {DB_USER} -p \
  {DB_NAME_PROD} < /tmp/{CLIENT_ID}_dump.sql
mysql -h {RDS_ENDPOINT} -u {DB_USER} -p \
  {DB_NAME_STAGING} < /tmp/{CLIENT_ID}_dump.sql

Phase 4 — Server Setup SERVER 20 min

9 Upload & run setup script (one command does everything)

# From local machine
scp -i {SSH_KEY_PATH} cicd/server/setup-mono-client.sh cicd/server/deploy-mono.sh ubuntu@{SERVER_IP}:/tmp/

# On server
ssh -i {SSH_KEY_PATH} ubuntu@{SERVER_IP}
sudo chmod +x /tmp/setup-mono-client.sh /tmp/deploy-mono.sh
sudo -E bash /tmp/setup-mono-client.sh {CLIENT_ID} \
  git@github.com:Logimax-Technologies/etail_development_src.git \
  --domain {DOMAIN} --staging-domain {STAGING_DOMAIN}
Script auto-creates: dirs, clones (staging+prod), 21 symlinks, webhook handlers, vhost config, uncomments index.php, generates database.php

10 Configure DB credentials

# Production
sudo nano /var/www/{CLIENT_ID}/prod/shared/config/global_configs.php
# Set: $hostname, $username, $password, $database

# Staging (if separate DB)
sudo cp /var/www/{CLIENT_ID}/prod/shared/config/global_configs.php \
       /var/www/{CLIENT_ID}/staging/global_configs.php
sudo nano /var/www/{CLIENT_ID}/staging/global_configs.php
# Change: $database → {DB_NAME_STAGING}

11 Activate vhost

sudo cp /tmp/{CLIENT_ID}-vhost.conf \
  /etc/apache2/sites-available/{CLIENT_ID}.conf
sudo a2ensite {CLIENT_ID}.conf
sudo apache2ctl configtest
sudo systemctl reload apache2

12 Upload assets

sudo cp -rp /var/www/existing_client/prod/shared/data/assets_img/* \
  /var/www/{CLIENT_ID}/prod/shared/data/assets_img/
# Repeat for assets_dist/ and assets_plugins/

13 Set webhook secret

# Same value as MONO_WEBHOOK_SECRET in GitHub
echo "export DEVOPS_WEBHOOK_SECRET='xxx'" \
  | sudo tee -a /etc/environment

Phase 6 — DevOps Tool Registration LOCAL 5 min

15 Register client

TOKEN=$(curl -s -X POST https://devops.logimaxindia.com/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "USER", "password": "PASS"}' | jq -r '.data.token')

curl -X POST https://devops.logimaxindia.com/api/clients \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"clientId":"{CLIENT_ID}","clientName":"{CLIENT_NAME}",
       "repoName":"etail_development_src","repoOrg":"Logimax-Technologies",
       "stagingBranch":"support","prodBranch":"Production",
       "baseUrl":"https://{DOMAIN}","serverFolder":"{CLIENT_ID}",
       "webhookPath":"/webhooks/deploy.php"}'

🔧 Quick Reference — Post-Setup Commands

Manual Deploy

# Staging
cd /var/www/{CLIENT_ID}/staging
git pull origin support

# Production
sudo bash /var/www/{CLIENT_ID}/prod/current/cicd/server/deploy-mono.sh Production

Rollback Production

# List releases
ls -lt /var/www/{CLIENT_ID}/prod/releases/

# Rollback to previous
sudo ln -sfn /var/www/{CLIENT_ID}/prod/releases/{PREV} \
  /var/www/{CLIENT_ID}/prod/current_tmp
sudo mv -Tf /var/www/{CLIENT_ID}/prod/current_tmp \
  /var/www/{CLIENT_ID}/prod/current
