# Placeholder and Data Mapping Reference

This document provides a detailed reference for all dynamic placeholders available in the Print Template System and their corresponding data sources in the backend.

---

## 1. Global / Bill Details
Mapped from the `billing` array in `receipt_helper.php`.

| Placeholder | Data Source (Table/Field) | Description |
| :--- | :--- | :--- |
| `{{invoice_no}}` | `ret_billing` (composite) | The full invoice number (e.g., BR-FY-123). |
| `{{bill_date}}` | `ret_billing.bill_date` | Date of the transaction (Formatted: DD-MM-YYYY). |
| `{{bill_time}}` | `ret_billing.created_time`| Time of the transaction. |
| `{{title}}` | Controller Logic | Dynamic title based on bill type (e.g., "Tax Invoice"). |
| `{{gold_rate}}` | `ret_billing.goldrate_22ct`| The 22ct Gold rate used for the bill. |
| `{{silver_rate}}` | `ret_billing.silverrate_1gm`| The Silver rate used for the bill. |

---

## 2. Customer Information
Mapped from the `customer` table via the billing record.

| Placeholder | Data Source (Table/Field) |
| :--- | :--- |
| `{{customer_name}}` | `customer.customer_name` |
| `{{customer_mobile}}` | `customer.mobile` |
| `{{customer_address}}` | `customer.address1` + `address2` |
| `{{customer_city}}` | `customer.city` |
| `{{customer_gstin}}` | `customer.gst_number` |
| `{{customer_pan}}` | `customer.pan` |

---

## 3. Items Loop (`{{#items}}`)
The items loop iterates over all line items in the bill.

| Placeholder | Description | Source |
| :--- | :--- | :--- |
| `{{sno}}` | Auto-incrementing serial number | Generated by Render Engine |
| `{{description}}`| Product name and details | `ret_bill_details.product_name` |
| `{{hsn_code}}` | HSN Code for taxation | `ret_bill_details.hsn_code` |
| `{{gross_wt}}` | Gross weight of the item | `ret_bill_details.gross_wt` |
| `{{net_wt}}` | Net weight of the item | `ret_bill_details.net_wt` |
| `{{qty}}` | Quantity | `ret_bill_details.piece` |
| `{{rate}}` | Rate per gram | `ret_bill_details.rate_per_grm` |
| `{{amount}}` | Total amount for the item | `ret_bill_details.item_cost` |
| `{{va_percent}}` | Wastage / VA percentage | `ret_bill_details.wastage_percent` |
| `{{mc}}` | Making Charges | `ret_bill_details.mc_value` |

---

## 4. Totals and Summary
Mapped after calculations in `receipt_helper.php`.

| Placeholder | Description |
| :--- | :--- |
| `{{sub_total}}` | Total taxable amount before GST. |
| `{{sgst_amount}}` | Total SGST calculated. |
| `{{cgst_amount}}` | Total CGST calculated. |
| `{{grand_total}}` | Final payable amount (including taxes). |
| `{{amount_in_words}}`| Grand total converted to words. |
| `{{remark}}` | User-entered remark for the bill. |

---

## 5. Payment Details (`{{#payment_breakdown}}`)
A loop for displaying multiple payment modes used in a single bill.

| Placeholder | Description |
| :--- | :--- |
| `{{mode}}` | Payment mode (e.g., Cash, Card, UPI). |
| `{{amount}}` | Amount paid in this mode. |

---

## Implementation Note for Developers
When adding new placeholders:
1. Add the placeholder to the `print_template_placeholders` database table.
2. Update `receipt_helper.php` in the `map_billing_data_to_template` function to ensure the new key is populated in the `$mapped` array.
3. Refresh the designer to see the new placeholder in the sidebar.
