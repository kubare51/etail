### ⚠️ Test 1.5: get_po_ratecut_balance_details() - Balance Amount Calculation

**Status**: **WARNING** ⚠️

**Code Analysis**:
```php
// Line 8993: Balance amount calculation
(IFNULL(p.tot_purchase_amt, 0) - (IFNULL(crdr.dr_amt, 0) + IFNULL(crdr.cr_amt, 0))) as balance_amt
```

**Issue Found**:
```
Current formula: tot_purchase_amt - (dr_amt + cr_amt)
This SUBTRACTS both DR and CR amounts!

Expected formula should be: tot_purchase_amt - dr_amt + cr_amt
```

**Impact**:
- 🔴 **BUG**: Credit amounts are being subtracted instead of added
- This will show LOWER balance than actual
- Financial calculations will be incorrect

**Example**:
```
PO Amount: 50,000
DR Amount: 2,000 (should subtract)
CR Amount: 500 (should add)

Current (WRONG): 50,000 - (2,000 + 500) = 47,500
Expected (CORRECT): 50,000 - 2,000 + 500 = 48,500

Difference: 1,000 (underreported balance)
```

**Recommendation**: 
```php
// FIX REQUIRED - Change line 8993 to:
(IFNULL(p.tot_purchase_amt, 0) - IFNULL(crdr.dr_amt, 0) + IFNULL(crdr.cr_amt, 0)) as balance_amt
```

**Result**: ⚠️ **BUG FOUND** - Balance amount calculation has incorrect CR/DR logic.
